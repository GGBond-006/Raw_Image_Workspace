## 一、整体框架

```
┌──────────┬──────────────────────────────────────────────┐
│          │ 页头 64px：面包屑 + 商品标题 │ 步骤条 │ 主操作   │
│ 左侧导航 ├──────────────────────────────────────────────┤
│  224px   │                                              │
│          │ 内容区（padding 20px 28px，卡片间距 16–20px）    │
│          │                                              │
│          ├──────────────────────────────────────────────┤
│          │ 底部操作栏 68px：左侧辅助说明 │ 右侧主按钮        │
└──────────┴──────────────────────────────────────────────┘
```

- **左侧导航**：Logo、搜索（Ctrl K）、主导航（工作台 / 生图任务 / 素材库 / 品牌 LOGO 库 / 提示词模板 / 生图平台）、最近任务，底部固定显示生图平台状态卡和当前用户。
- **页头**：左侧是面包屑和商品标题（带品牌标签），右侧是三步步骤条（导入素材 → 核对参数 → 生成与验收）。第三步没有底部栏，主操作放在页头右侧。
- **底部操作栏**：用于第一、二步这类向导页面，每屏只放 **1 个主按钮**。
- **画布基准**：1600 × 1000（原型图按 2 倍分辨率导出）。

## 三、组件规范

| 组件 | 规范 |
|---|---|
| 按钮 | 主按钮（靛蓝实心）、次按钮（白底细描边）、幽灵按钮（无底）；高度 34，大号 40，小号 28 |
| 状态标签（Pill） | 高 22，圆角 6，浅色底 + 深色字；只用 ok / warn / bad / brand / gray 五种 |
| 卡片 | 白底 + 1px 描边；标题栏 16px 20px，下方有分隔线；卡片标题右侧可放标签或次要操作 |
| 缩略图 | 浅灰底 `#F7F8FA`，图片 `contain` 完整显示；角色角标放左上角，状态放右上角 |
| 图标 | 统一用线性图标（Lucide 风格，描边 1.8），**禁止使用 emoji** |
| 步骤条 | 圆形序号，已完成显示对勾（浅靛底），当前步骤为靛蓝实心 + 光圈，未开始为灰色描边 |
| 表单 | 标签在上（12px 灰色粗体），下拉框高 36；需要人工确认的字段用 warn 浅黄底 + “确认”按钮 |

## 四、设计原则

1. **以图为主**：素材、参考图、成品图一律用真实缩略图展示，文字压缩成一行说明。
2. **一屏一个主操作**：主色只用在当前最重要的动作上。
3. **状态只用三种颜色**：通过（绿）、需要注意（琥珀）、已排除（红），不再引入其他颜色表示状态。
4. **人工介入点要显眼**：所有需要人确认或处理的地方，都用 warn 色并配上明确的按钮。
5. **文件名透明**：涉及输出的地方直接显示最终文件名（等宽字体），比如 SKU 组合矩阵。
